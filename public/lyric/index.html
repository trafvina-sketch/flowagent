Cấu hình Gemini API Key

Ứng dụng này sử dụng **Google Gemini AI** trực tiếp từ trình duyệt của bạn để nhận diện âm thanh và khớp lyric chính xác.

Để lấy API Key miễn phí hoặc có phí, truy cập Google AI Studio:
https://aistudio.google.com/

Lưu ý: API Key của bạn được lưu hoàn toàn ở **localStorage** trên máy tính của bạn và chỉ được gửi trực tiếp đến API Google Generative AI.
